## Task A — VantageFlow Marketing Site

B2B SaaS website with 4 pages (Home, Product, Pricing, Contact).  
Built with Next.js, TypeScript, Tailwind CSS.

```bash
cd task-a
npm install
npm run dev       # localhost:3000
npm run build
npm run lint
```

Deploy: `cd task-a && npx vercel --prod`
